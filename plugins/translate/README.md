# 翻译

`tools.translate` 0.1.3：Go 进程后端与隔离 HTML 页面，不需要 API Key。

## 使用

主输入框输入文本后选择「翻译」，页面自动显示结果。按名称打开时，可在页面输入原文并点击「翻译」或按 Command/Ctrl + Enter。编辑原文会清除旧译文，避免结果错配；切换原文语言、目标语言或引擎立即重新翻译。输入法组合期间不响应翻译快捷键。译文区域提供「复制」按钮；没有选中文本时按 Command/Ctrl + C 复制完整译文，选中原文或页面文本时保留系统正常复制。没有译文时复制按钮禁用，复制失败时提示手动选中译文重试。

在司南「设置 → 翻译」配置常用目标语言和默认引擎，默认分别为简体中文与 MyMemory。页面默认使用「常用语言（自动）」：原文与常用目标语言相同时译为英语，否则译为常用目标语言；设置英语为常用语言时，相同语言仍保持英语。手动指定目标语言优先于该规则，页面临时切换不修改默认设置。

原文/译文不持久化，不写入日志。搜索匹配只在本地进行，打开带入文本的翻译页面后才向所选服务发送原文；更换引擎也会发送原文。没有自动跨服务回退。页面内最多 5000 个 Unicode 字符，主输入框匹配最多 20000 UTF-8 字节。

## 免费服务与限制

- **Google**：使用 `translate.googleapis.com/translate_a/single` 免费网页接口，不属于 Google Cloud 官方付费 API。按服务返回的语言识别结果决定目标语言，相同语言可能需要第二次请求。接口没有稳定性保证，可能因所在网络、限流或接口变化不可用。参考[接口使用说明](https://github.com/ssut/py-googletrans#note-on-library-usage)。
- **MyMemory**：使用[公开 REST API](https://mymemory.translated.net/doc/spec.php)，每次最多 500 UTF-8 字节，超过后提示缩短文本或切换引擎，不自动拆分。免费匿名额度受服务端限制，额度用尽时显式提示。单个无重音拉丁字母词（含缩写、连字符和撇号）在自动模式下优先按英语处理，避免短词统计识别误判；其他原文通过本地 whatlanggo 识别。单词可能属于多种语言，需按其他语言翻译时手动选择原文语言。短句、混合语言及繁简识别可能不准确，可手动指定原文语言。不调用其贡献/上传翻译接口。

原生后端只请求上述两个固定 HTTPS 端点，拒绝重定向；不回显网络错误中的原文、URL 或服务端响应正文。后台任务最多 4 个，整体 12 秒超时，结果在 30 秒后失效并在下次调用时清理；通过启动/轮询/取消适配宿主 500 毫秒页面调用预算。关闭视图尽力取消，强制关闭后仍由超时回收请求。切换或编辑时取消旧任务，并拒绝过期结果覆盖新内容。

## 宿主与平台

需要支持宿主 ADR 0061 的 `commands[].inputMatchScore` 字段（旧宿主会拒绝本版清单），以及已实现 API 1 `select` 设置、UI Bridge 2 `command.execute`/`launch.get`、声明式 `inputMatchers` 和隔离 HTML 视图的宿主（对应 ADR 0029、0043 及当前设置协议；以实际能力为准）。复用已固定的 SDK 快照，后端 RPC、UI 桥及权限字段无变更；0.1.3 新增使用清单内容匹配分数字段，SDK 快照没有对应的清单类型，因此无需更新快照。后端为普通原生进程，不构成操作系统安全沙箱；现有协议尚不提供网络域名授权，因此未填入不受支持的网络权限。

macOS、Windows、Linux 的 arm64/amd64 均使用纯 Go 后端；Windows 包入口为 `backend/plugin.exe`，其他为 `backend/plugin`。页面只使用本地 HTML/CSS/JS、标准表单和窄桥，不从页面发网络请求，不需要放宽 CSP。遵循 WKWebView、WebView2 119+、WebKitGTK 2.40+ 的宿主基线，主题使用系统深浅模式。X11/Wayland 不影响翻译业务；窗口、输入法和焦点由宿主适配，仍需分别实机验收。

构建：`node scripts/build-translate.mjs --all`（六目标）或 `--target=windows-amd64`。构建输出 `bin/targets/<os>-<arch>/translate`，现有打包入口附加对应 ZIP 和 SHA-256；未上传 Release 或登记商店。执行 `npm test` 运行离线网络夹具、异步交互状态测试及既有回归；不打开桌面或浏览器。

已完成本机无界面测试及六目标交叉构建不代表其他平台运行通过；真实 WebView、输入法、焦点及服务可达性需要分别验收。不得据此声明已发布或全平台适配完成。
