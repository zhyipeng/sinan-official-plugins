# 剪贴板

`tools.clipboard` 0.2.1，需要司南 0.2.1 或更新版本，初始化检查 `hostCapabilities` 中的 `clipboard.v1`，旧宿主明确拒绝激活。独立安装的官方原生插件，安装时需要明确确认原生信任。

`⌘/Ctrl + Shift + V` 打开历史；搜索、↑/↓ 选择、Enter 或“粘贴”会恢复原应用并输入完整条目。也可双击粘贴或点“复制”手动粘贴。支持文本和图片预览、删除与清空。热键可在司南“设置 → 插件快捷键 → 剪贴板历史”中按键录入、恢复默认并保存，重启后保留。热键被占用时可在该处修改，也可按名称搜索打开，冲突见插件中心诊断。

启动后持续监听，默认最多 200 条、64 MiB；单文本最多 256 KiB，PNG 最多 8 MiB / 1600 万像素。不保存富文本或文件列表。内容按散列去重，保存在宿主提供的原生 dataDir，重启后恢复。文件未加密，不上传或记录到日志；macOS 跳过声明为 Concealed、Transient、AutoGenerated 的剪贴板内容。禁用插件停止监听，卸载保留历史；清空按钮删除本插件历史文件。当前宿主私有文档清理不包含此原生目录。

macOS 自动粘贴须在“系统设置 → 隐私与安全性 → 辅助功能”为司南开启权限；缺少权限时会弹出引导，点击“打开系统设置”跳转，开启后返回重试即可。Windows 受系统前台切换和应用完整性级别限制。Linux 读取/写入需要 X11 的 `xclip` 或 Wayland 的 `wl-clipboard`；自动粘贴仅支持 X11 + `xdotool`，Wayland 使用“复制”手动粘贴。系统拒绝输入时已选内容仍留在剪贴板。

在仓库根目录执行 `node scripts/build-clipboard.mjs`，输出 `bin/targets/<os>-<arch>/clipboard`。`npm run package` 会附带本机平台/架构的 ZIP；用 `npm run package:all` 构建六目标，任一系统均可用 `--target=windows-amd64` 等显式目标交叉构建，不自动安装或发布；Windows 构建清单入口自动为 `.exe`。Go 后端测试在此目录执行 `go test -race ./backend`，不访问真实剪贴板。真实热键、焦点和跨应用输入尚未验收。


0.1.1 的跨平台调整：Windows 支持常见 DIB / DIBV5 的上下行方向、24/32 位和位域，写入 PNG 保留透明度并提供白底 DIB 回退；Linux 按实际 MIME 精确选择文本/PNG，缺少 xclip 或 wl-clipboard 时显示对应安装提示。错误提示按宿主平台区分，Windows/Linux 不再展示 macOS 权限说明。后端仍不包含任意宿主调用或完整 Wails Bridge。

## 0.2.0 重构

文本/PNG 系统读写、macOS 敏感类型过滤、Windows PNG/DIB 转换与 Linux 依赖判断统一由宿主负责；插件仅通过 Go SDK 的 `ClipboardRead` / `ClipboardWrite` 调用。历史、500 毫秒轮询、去重、容量与持久化继续留在插件，不新增宿主监控。平台适配与对应无界面测试已迁至宿主，插件后端为纯 Go，不再依赖 Cocoa/CGO，可交叉构建六目标。Linux 工具依赖仍由宿主使用，自动粘贴的权限与 Wayland 限制不变。原生进程信任与 OS 沙箱边界不变；已发布 0.1.2 资产保持不变，不登记未发布包。

## 0.2.1 历史排序与图片预览

点击“复制”或执行粘贴，在成功写入系统剪贴板后将该项移到列表首位，保留其他条目的相对顺序和采集时间；排序保存到历史索引，重启后恢复。系统写入失败时顺序不变；复制成功但排序保存失败时明确提示，并保留原顺序。

左侧图片使用按可见区域加载的 64×48 缩略图，最多同时读取两张，缓存最多 200 项；右侧使用独立 PNG 预览，最高 1280×960，在详情区域等比放大并保留完整画面。复杂图片会继续缩小，使 PNG 不超过 128 KiB、命令响应保持在宿主既有 192 KiB 预算内。仅预览降采样，复制仍使用原始图片。页面通过 Canvas / createImageBitmap 解码绘制，不新增网络地址、资源来源或宿主权限。

三端共用 Go 与静态 JS/CSS，沿用 Safari 16.4 / Chromium 119 / Firefox 115 构建目标；未改变系统剪贴板适配、X11/Wayland 依赖、公共协议或 SDK。新增 thumbnail 为本插件内部命令，包内清单与页面一并更新，商店登记与历史发行资产不变。本机通过剪贴板 Go 竞态回归、静态检查、3 项前端无界面测试及六目标交叉构建；未执行 Windows/Linux 目标运行、三端 WebView、DPI、真实剪贴板或交互验收。
